1. Key Concepts
Term	Definition	Location / Example
Module	A single .py file containing reusable code such as functions, classes, or variables.	my_package/math_utils.py
Package	A directory containing related Python modules. It usually contains an __init__.py file.	my_package/
Third-Party Package	An external Python library installed using pip.	numpy, pandas
Standard Library	Python's built-in modules that do not require separate installation.	math, os, datetime
Import	Used to access code from another module or package.	import numpy as np
